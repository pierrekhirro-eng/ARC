# ARC Studio

Novo projeto criado do zero.

## Conceito
**ARC — Digital products, precisely built.**

ARC não é uma continuação visual de nenhum projeto anterior. A direção mistura:
- editorial contemporâneo
- produto digital
- arquitetura
- direção de arte
- software premium

## Rodar

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
